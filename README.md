# B&B Unikoop

The website of B&B Unikoop, the official SKF distributor for North Macedonia.

| Folder | What | Runs on |
|---|---|---|
| `frontend/` | Next.js site | Vercel |
| `docs/` | Architecture plan and notes | |

Frontend: `cd frontend && npm install && npm run dev`, then open http://localhost:3000. It needs `frontend/.env.local` (database URLs).

The plan for the separate API backend is in [docs/architecture-plan.md](docs/architecture-plan.md).
